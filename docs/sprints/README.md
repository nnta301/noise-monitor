# Roadmap and sprint tracking

Each sprint is planned to last approximately two weeks; no specific dates have been assigned. One Project board is used throughout, with the statuses defined in the [workflow](../workflow.md).

1. **Sprint 1 — Core Telemetry Pipeline:** measure, transmit, store, and display data.
2. **Sprint 2 — Noise Detection & Night Reports:** 30-second threshold, alerts, events, and nightly reports.
3. **Sprint 3 — Reliability & Final Delivery:** reconnection, backfill, overnight testing, and delivery completion.

Details are currently prepared only for [Sprint 1](sprint-01.md). Sprints 2–3 will be planned after the team reviews earlier results.
